# Townes reference values

`test_townes_reference.py` compares package output with singular values
generated by `null_residuals()` in:

- Repository: <https://github.com/willtownes/scrna2019>
- Commit: `aad379acc2ee24e348e4925015d9de986ceb69f5`
- Source file: `util/functions.R`

The checked-in values were generated with:

```bash
Rscript tests/townes_reference/generate_reference.R \
    /path/to/scrna2019/util/functions.R
```

The R script is manual provenance tooling. Normal tests use only the checked-in
values and do not require R or a local copy of the reference repository.
